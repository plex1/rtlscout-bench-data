- **Design**: `design_opt10.sv` (2-stage pipelined adder: 16+16 bit split)
- **Area-Delay Product**: 4,574,150 (best achieved)
- **Delay**: 990 ps, **Area**: 4,619 μm²

### What Worked Best
**2-stage pipelined adder (16+16 split)** - Splitting the 32-bit accumulation into two 16-bit adds with the carry propagating between stages reduced the critical path through the adder chain while keeping area low. The synthesis tool mapped this efficiently.

### What Didn't Work
- **Complex prefix adders (Sklansky, Brent-Kung)**: Multiple simulation failures due to subtle carry logic bugs
- **16-bit group CLA**: Verilator syntax issues with nested generate blocks
- **Registered intermediate signals (design_opt19.sv)**: Added pipeline latency that broke cycle-accurate behavior
- **Optimized skew/deskew with shared arrays (design_opt16.sv)**: Broke functional correctness

### Lessons Learned
1. **Simple structural changes beat complex arithmetic optimizations** - The 2-stage split adder was trivial to verify and gave the best AD product
2. **Cycle-accurate behavior is fragile** - Any pipelining inside the PE that changes latency breaks the testbench
3. **Target delay has minimal effect** - The synthesis tool converged to similar results across 200-1200ps targets
4. **Verification first** - Complex adder structures (prefix, CLA trees) introduced bugs that were hard to debug

### Next Time
- Focus on **retiming/register placement** rather than adder algorithm changes
- Explore **multiplier optimization** (Booth encoding, partial product reduction) since multiply dominates the critical path
- Try **physical-aware optimizations** (floorplanning hints, don't-touch attributes)
